# 💻 Welcome to Code-Laboration – A Live Code Presentation Tool  
React | Tailwind | Typescript | Node.js |

Hello! This is the showcase for **Code-Laboration**, an interactive tool I co-developed for presenting code during lectures or live sessions. It’s designed to mimic the natural flow of live coding, helping audiences follow along more effectively.

## ✨ Key Features  
- Add and display multiple lines of code with smooth, stacked transitions  
- Max display limit of 15 lines with automatic removal of the oldest lines  
- Jump directly to any specific line with ease  
- Simple, intuitive UI with interactive navigation controls  

<br>

## 🛠 Technologies Used  
- **React** - Front-End Development
- **Vite** - Fast Front-End Development And Bundling 
- **MongoDB** - Database   
- **AWS Lightsail** - Deployment
